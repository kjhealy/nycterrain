# Package index

## Elevation rasters

Accessor functions returning
[`terra::SpatRaster`](https://rspatial.github.io/terra/reference/SpatRaster-class.html)
objects.

- [`nyc_terrain_100ft()`](https://kjhealy.github.io/nycterrain/reference/nyc_terrain_100ft.md)
  [`nyc_terrain_50ft()`](https://kjhealy.github.io/nycterrain/reference/nyc_terrain_100ft.md)
  : Get the NYC bare-earth elevation raster at 100ft or 50ft resolution
- [`nyc_terrain_path()`](https://kjhealy.github.io/nycterrain/reference/nyc_terrain_path.md)
  : Get the file path to a bundled NYC terrain GeoTIFF

## Contour data

Lazy-loaded `sf` contour lines.

- [`nyc_terrain_contours_sf`](https://kjhealy.github.io/nycterrain/reference/nyc_terrain_contours_sf.md)
  : NYC bare-earth elevation contours
